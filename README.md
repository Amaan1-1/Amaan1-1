## Featured Projects

### 1. WorkforceHQ — AI Workforce Analytics Platform

An analytics platform designed to make operational workforce data easier to query and interpret. I led a **team of three** and worked on the data workflows, integrations, and AI-powered querying experience.

- Designed **automated ETL pipelines** and data-validation workflows to prepare operational data for analysis.
- Integrated backend services through **REST APIs** and SQL-based data processing.
- Implemented a **Retrieval-Augmented Generation (RAG)** workflow using LangChain, embeddings, and vector-database retrieval to ground natural-language questions in relevant workforce data.
- Focused on turning raw operational information into clearer insights for decision-making.

**Technologies:** Python · PostgreSQL · React · OpenAI API · SQL · REST APIs · ETL · LangChain · Vector databases

### 2. Bellhaven CRM Data Reconciliation & Sales Operations Pipeline

A data-quality and sales-operations workflow that compares facility information collected from a website with CRM accounts, flags discrepancies, and prepares proposed changes for review.

- Built a **web-scraping and record-matching pipeline** to compare facility details against hundreds of CRM accounts.
- Identified potential ownership changes, duplicates, missing accounts, and rebranding events, then generated recommended actions.
- Created a **Flask review interface** backed by SQLite so proposed changes can be checked before updates are sent to the CRM sandbox API.
- Structured the workflow for scheduled runs and repeatable processing, with tests for the record-matching logic.

**Technologies:** Python · Flask · SQLite · Web Scraping · CRM APIs · Data Quality · Pytest · GitHub Actions

**Repository:** [View the source code](https://github.com/Amaan1-1/clipboard-sales-ops)

### 3. Toronto Urban Heat & Green Infrastructure Analytics

A geospatial web application focused on exploring urban heat vulnerability and supporting analysis of potential green-infrastructure locations in Toronto. This project combines interactive mapping with spatial calculations to help make location-based patterns easier to explore.

- Built interactive map functionality with **Mapbox GL JS**, using GeoJSON to represent and work with geographic data.
- Developed spatial tools for distance calculations and multi-point buffer analysis using **Turf.js**.
- Added filtering across **five vulnerability levels** to compare areas and explore locations that may need additional attention.
- Exploring geospatial machine-learning approaches to help rank priority sites for green-infrastructure investment.

**Technologies:** Next.js · React · Mapbox GL JS · Turf.js · GeoJSON · Spatial Analytics · GIS

**Repository:** [View the geospatial web app](https://github.com/Amaan1-1/Geospatial_WebApp)
